# HeritageWatch

An open-source, educational platform for understanding and monitoring threats facing cultural heritage sites around the world — an interactive map and searchable database with transparent, source-backed status classifications (Safe, Moderate Concern, High Concern, Critical Concern) rather than numerical risk scores.

Status: early development. Not yet deployed.

## Documentation

Project planning docs (architecture, data model, research methodology) are being developed alongside the code.
